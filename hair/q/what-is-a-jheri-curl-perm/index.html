Home / Hair / Relaxer, texturiser, perm and keratin: what is the difference

Question

what is a jheri curl perm

  • Tier D Untested
  • Harm signal
  • Last checked 2026-11-12
  • Not yet clinically reviewed

Short answer

A Jheri curl is a perm, and a perm adds curl; a relaxer straightens, and a texturiser loosens curl by being left on for less time. Stylists say relaxer and texturiser use the same kind of chemical. Ask for a service by what you want: straighten, loosen the curl or add curl, and ask how long it will stay on.
